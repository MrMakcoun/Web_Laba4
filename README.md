# Mesto — лабораторная работа № 4, вариант 7

Фотогалерея с редактированием профиля и аватара, добавлением и удалением карточек, лайками и просмотром фотографий. В форме «Новое место» поле «Город / Регион» принимает от 2 до 30 символов по шаблону варианта. После добавления карточки в правом нижнем углу появляется уведомление.

## Запуск

Понадобится Node.js 20.19+ в ветке 20 или Node.js 22.12+.

```sh
npm ci
npm run dev
```

Vite откроет страницу в браузере. Для сборки и её локального просмотра:

```sh
npm run build
npm run preview
```

Статические файлы сборки находятся в `dist/`.
